# Forever Lore Codex

A lore guide to *World of Warcraft: Forever* for Warcraft veterans: what's canon, what's new and what's still unwritten. It covers the runway from the War of the Ancients to Year 1, the branch point where Forever leaves the old timeline, common assumptions checked against Forever's canon, the open story hooks (as a quest log), who's tied to what, and a reading stack. Single static page: `index.html`.

Regenerate the link-preview image (`og.png`, from `og/card.html`) and the icons with `python og/build.py` (needs Edge and Pillow). `favicon.svg` is hand-written; the build draws the matching `favicon.ico` and `apple-touch-icon.png`.

Companion site: [Forever Class Codex](https://tuckerscottalleborn.github.io/forever-class-codex/).
